# Changelog

## October 2026: first public release

- Apache / LiteSpeed, Nginx, Caddy and Cloudflare output from one set of switches
- Bulk redirects with chains shortened to one hop and loops removed
- AI crawler blocking (training crawlers and search/assistant fetchers), bad bot blocking and a matching robots.txt
- Domain moves, removing `.php`/`.html` from URLs, password-protected folders and IP blocking
- Security headers, HSTS, CSP (report-only), WordPress hardening, caching, compression, WebP, hotlink protection and custom error pages
- Share links that restore an exact setup
- Tested on Apache, Nginx, Caddy, LiteSpeed and Cloudflare: see [TESTING.md](TESTING.md)
