.htaccess, Nginx & Caddy Rule Generator

Pick a preset or flip the switches — force HTTPS, fix www and trailing slashes, bulk redirects, security headers, AI crawler blocking, caching — and copy correctly-ordered code for Apache, LiteSpeed, Nginx, Caddy or Cloudflare. No regex required.

⚙️ Apache, LiteSpeed, Nginx, Caddy & Cloudflare 🛡️ AI crawler blocking 🔗 Shareable config links

Writing rewrite rules by hand is where most small mistakes happen — a missing flag, the wrong rule order, a redirect chain that adds an extra hop, or a regex that works for Apache but does nothing on Nginx (which never reads a .htaccess file at all). This generator builds correct, ready-to-paste code for four servers plus Cloudflare, updates live as you toggle options, and gives you a link to the exact configuration so you can save it or share it.

Preset
Redirects +
Force HTTPS

Redirect every plain HTTP request to HTTPS with a permanent (301) redirect.

Canonical www

Pick www or non-www so only one is indexed. Combined with HTTPS into a single redirect — no chains.

Trailing slash

Enforce one URL format. Leave off for WordPress — it already follows your permalink setting.

Remove .php / .html from URLs

Turn /about.php into /about. Old links redirect to the clean address, and the clean address still opens your file. For hand-built PHP and static sites; WordPress and most frameworks already have clean URLs.

Bulk redirects

Paste old and new URLs, one pair per line. Chains are shortened automatically, so every old URL goes straight to its final address in one hop.

Separate old and new with a space, tab or comma. Full URLs work too.
Move from an old domain

Moving to a new domain? Every page on the old domain goes to the same page on your domain, in one hop. Pages you renamed in Bulk redirects go straight to their new address.

Your new domain is the one in “Your domain” below.

Custom error pages

Show your own page instead of the server’s plain default for 404, 403 and 500 errors. Leave a box empty to skip it.

Paths to pages on your own site. WordPress themes already show their own 404 page, so leave that box empty on WordPress.

Security & bots +
Security headers

X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, plus HSTS when Force HTTPS is on.

Forces HTTPS on every subdomain, so only tick it if they all have a certificate. Preloading is hard to undo — submit at hstspreload.org when ready.

Report-only mode logs violations in the browser console without blocking anything, so it can't break your site.

Block AI crawlers

GPTBot, ClaudeBot, CCBot, Bytespider, Meta and more — plus a matching robots.txt. Pick whole groups or individual bots.

Blocking search fetchers also removes your pages from AI answers and their citations.

Block bad bots

Return a 403 to SEO crawlers, vulnerability scanners and scripted traffic. Each group is a separate choice.

Scripting tools are also used by uptime monitors, webhooks and integrations. Check that none of yours rely on them first.

Protect sensitive files

Deny .env, .git, other dotfiles, backups, SQL dumps and logs. Keeps .well-known open for SSL.

Disable directory listing

Stop the server showing a file list for folders without an index page.

WordPress hardening

Lock down the files and URLs attackers probe first on WordPress sites.

Password-protect a folder

Ask for a username and password before anyone can open a folder, such as a staging copy or admin area, or the whole site.

Use / to protect the whole site. The password file is where Apache and Nginx look for your login; keep it outside your public web folder.

Block IP addresses

Return a 403 to specific IP addresses or ranges, such as a scraper or attacker you’ve spotted in your logs.

One IP address or range (CIDR) per line, IPv4 or IPv6.
Hotlink protection

Stop other websites from embedding your images and using your bandwidth. Your own pages, search engines and direct visits still load them. Uses your domain below.

Performance +
Compression

Gzip text, CSS, JS, JSON, SVG and fonts (zstd + gzip on Caddy). LiteSpeed does this automatically.

Browser caching

Cache images, CSS, JS and fonts for a year; never cache HTML. Assumes versioned asset URLs (WordPress adds ?ver=).

WebP image redirects

Serve photo.jpg.webp automatically when it exists next to photo.jpg and the browser supports WebP.

Used for Nginx’s server_name, Caddy’s site address, Cloudflare rules, redirect targets and hotlink protection. Apache’s other rules work for any domain automatically.
